# Mehr Medical — демо-сайт клиники

Демо от [CaravanHouse](https://caravanhouse.uz): сайт вымышленной многопрофильной клиники в Ташкенте.
Живая версия: https://clinic.caravanhouse.uz

Что показывает демо:
- **Структура клиники**: филиалы, этажи и отделения, карточка отделения с услугами и врачами.
- **Врачи**: фильтры по отделению и языку приёма, поиск, ближайшее свободное окно у каждого врача.
- **Онлайн-запись по шагам**: отделение → врач (или «любой свободный») → дата и время → контакты, в конце файл .ics для календаря.
- **Поиск** по врачам и услугам прямо в первом экране, **прайс** с поиском и фильтром, **чек-апы**, филиалы и FAQ.
- Русский и узбекский (`/ru`, `/uz`), адаптивная вёрстка.

Это демо: клиника, врачи, адреса, телефоны и цены придуманы, запись никуда не отправляется.
Расписание считается детерминированно (`lib/slots.ts`); в настоящем проекте сюда подключается МИС клиники.

Стек: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4. Хостинг — Vercel.

```bash
npm install
npm run dev   # http://localhost:3000
```
